LIYANSH PICKLES WEBSITE
======================

FILES
-----
index.html       The complete website. Open this file in a browser.
assets/          Local photos cropped from the reference image.

EDITING PRODUCTS
----------------
Open index.html in a text editor and find the `const products = [...]` list
inside the script near the bottom. Each product has a name, category, image,
description, rating, and prices. Update these values to match the real catalog.

Prices currently use sample values of Rs 400 for 500 g and Rs 800 for 1 kg.
Replace the sample reviews and ratings with real customer feedback before
publishing.

IMAGES
------
The first five pickle product images and the hero background are in assets/.
Green chilli, amla, and mixed vegetable pickle photos currently load from
external image URLs in the product list. Replace those URLs with approved
Liyansh product photos when available.

CONTACT AND SOCIAL LINKS
------------------------
The phone and WhatsApp number is +91 93465 94054. To update it, change the
number in the header, contact section, WhatsApp links, and `waNumber` near the
bottom of index.html.

Replace the Instagram and Facebook placeholder links with the official brand
profile URLs. The contact form and checkout open WhatsApp with a prepared
message; this static website does not store submissions or collect payments.

PUBLISHING
----------
This is a static website and can be hosted on a static web host. Keep the
assets folder beside index.html when uploading the site so its local images
continue to work.
